## 実装範囲

要件定義書 v4.2 と基本設計書 v1.1 に基づき、次の機能を実装しました。

- 筋トレ・自重・有酸素の記録、複数セッション、セット編集・削除・並べ替え。
- 初期53種目、種目マスタ、テンプレートとセット数指定。
- 休憩タイマー、無音通知、終了時刻管理と復元処理。
- カレンダー、種目別ボリュームグラフ、体重記録と日平均、期間サマリー。
- 筋トレ・有酸素・体重の CSV をダウンロードへ保存。
- Room による端末内保存、DataStore 設定、バックアップ無効化。

アプリにはインターネット権限・ストレージ権限を付けていません。通知は必要時に許可を求めます。元の設計文書や既存のユーザー変更は更新していません。
