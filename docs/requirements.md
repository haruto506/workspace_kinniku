## 1. アプリケーション概要

筋力トレーニングおよび有酸素運動の実施内容を日々記録し、後から振り返るための個人用アプリケーション。

| 項目 | 内容 |
|---|---|
| 提供形態 | ネイティブ Android アプリ |
| 対応 OS | Android 13 以上 |
| 配布方法 | ビルドした APK を端末に直接インストール（ストア公開なし） |
| 利用者 | 依頼者本人ひとりのみ |
| データ保存先 | 端末内のみ（ローカル保存） |
| 表示言語 | 日本語のみ |
| 技術スタック | Kotlin ＋ Jetpack Compose ＋ Room |

## 2. 前提条件・制約

- サーバーおよびクラウドサービスは使用しない。すべての機能がオフラインで完結すること。
- ユーザーアカウント、ログイン、認証の仕組みは持たない。
- 複数端末間でのデータ同期は行わない。
- 多言語対応は行わない。
- ダークモードには対応しない。ライトテーマ固定とする。
- 画面は縦画面固定とする。端末を横にしても回転しない。

## 3. データモデルの基本構造

### 3.1 記録の階層

```
日付
 └ セッション（1 日に複数持てる。名前は任意）
     └ 種目（複数持てる。順番を持つ）
         └ セット（複数持てる。順番を持つ）
```

- 1 日に複数のセッションを登録できる。同じ日の朝と夜のトレーニングを別々の記録として扱える。
- セッションには任意で名前を付けられる。名前の入力は必須ではない。
- セッションは時刻を持たない。日付のみで管理する。

### 3.2 種目マスタ

種目はマスタとして管理する。1 件の種目は以下の属性を持つ。

| 属性 | 内容 |
|---|---|
| 種目名 | 任意の文字列。最大 50 文字 |
| 部位 | 7 区分から 1 つ（3.3 参照） |
| 区分 | 「筋トレ」または「有酸素」 |
| 自重フラグ | 自重種目かどうか（3.6.2 参照）。有酸素種目では使用しない |

- 区分に応じて、記録時の入力項目を切り替える。
  - 筋トレ種目: 重量・回数を入力する
  - 有酸素種目: 実施時間を入力する
- ユーザーは種目を追加・編集・削除できる。追加時には部位・区分・自重フラグを設定する。
- 種目名は重複を許さない。削除されていない種目どうしで同名の登録を禁止する。削除済み種目と同じ名前は新たに登録できる。

### 3.3 部位

部位の区分はアプリ側で固定とし、ユーザーは部位の追加・変更・削除を行えない。部位は以下の 7 区分とする。

| 部位 | 用途 |
|---|---|
| 胸 | 筋トレ種目 |
| 背中 | 筋トレ種目 |
| 脚 | 筋トレ種目 |
| 肩 | 筋トレ種目 |
| 腕 | 筋トレ種目 |
| 体幹 | 筋トレ種目 |
| 有酸素 | 有酸素種目 |

### 3.4 種目属性のスナップショット保持

- 記録は、種目マスタへの参照と、記録した時点の種目属性のコピーの両方を保持する。コピーする属性は種目名・部位・区分・自重フラグの 4 つとする。
- 過去記録の表示および集計には、記録時点のコピーを使用する。
- 種目マスタの変更は、以降の新規記録にのみ反映する。マスタを編集しても過去の記録内容および集計値は変化しない。
- この方式により、種目の区分・自重フラグ・部位・名称はいつでも変更できる。使用実績による変更制限は設けない。
- 種目を削除した場合も、その種目を使用している過去の記録は削除されずそのまま残る。削除された種目は新規記録時の種目一覧に表示されなくなるのみとする。過去記録の表示および集計には引き続き反映される。
- 種目を削除した時点で、その種目を含むすべてのテンプレートから当該種目を自動的に取り除く。

### 3.5 種目の初期データ

- 筋トレ種目 53 件を初期登録する。具体的な種目名・部位・自重フラグは「8.1 付録 A」に定める。
- 有酸素種目は初期登録しない。ユーザーが自分で追加する。

### 3.6 セットの記録項目（筋力トレーニング）

#### 3.6.1 通常の種目（自重フラグなし）

| 項目 | 内容 | 必須 |
|---|---|---|
| 重量 | 単位は kg のみ。0.5 kg 刻みで入力する | 必須 |
| 回数 | そのセットで行った反復回数 | 必須 |
| 休憩時間 | 休憩タイマーによる自動記録（4.4 参照）。タイマー未使用時は空のまま保存する | 任意 |
| メモ | フリーテキスト。最大 500 文字 | 任意 |

#### 3.6.2 自重種目（自重フラグあり）

| 項目 | 内容 | 必須 |
|---|---|---|
| 回数 | そのセットで行った反復回数 | 必須 |
| 休憩時間 | 同上 | 任意 |
| メモ | 同上 | 任意 |

- 自重種目では重量を入力しない。
- ベルトでプレートを下げるなどの加重は記録しない。加重して記録したい場合は、ユーザーが別の種目として自分で登録する。

#### 3.6.3 対象外の項目

- RPE・主観的なきつさの記録は行わない。

### 3.7 有酸素運動の記録項目

| 項目 | 内容 | 必須 |
|---|---|---|
| 種目 | 種目マスタの有酸素種目から選択する | 必須 |
| 実施時間 | 分単位の整数で入力する | 必須 |

対象外の項目: 距離、消費カロリー、心拍数・強度の記録は行わない。

### 3.8 体重の記録

| 項目 | 内容 | 必須 |
|---|---|---|
| 日付 | 記録日 | 必須 |
| 体重 | 単位は kg のみ。0.1 kg 刻みで入力する | 必須 |

- 1 日に何件でも記録できる。
- 体重記録は時刻を持たない。同じ日に複数件ある場合は登録順に並べる。
- 体脂肪率、体のサイズ（胸囲・腕回りなど）の記録は対象外とする。

### 3.9 入力値の許容範囲

| 項目 | 下限 | 上限 | 刻み |
|---|---|---|---|
| 重量 | 0.5 kg | 999.5 kg | 0.5 kg |
| 回数 | 1 回 | 999 回 | 1 回 |
| 有酸素の実施時間 | 1 分 | 999 分 | 1 分 |
| 体重 | 0.1 kg | 999.9 kg | 0.1 kg |
| 休憩タイマーの目安秒数 | 1 秒 | 3600 秒 | 1 秒 |

- 範囲外の値は保存できない。入力時にエラーとして扱う。

### 3.10 文字列項目の最大長

| 項目 | 最大長 |
|---|---|
| 種目名 | 50 文字 |
| セッション名 | 50 文字 |
| テンプレート名 | 50 文字 |
| セットのメモ | 500 文字 |

## 4. 機能要件

### 4.1 種目の選択

- 種目を選択する画面では、累計の使用回数が多い順に種目を並べる。
- 累計の使用回数とは、その種目がセッションに登録された回数を指す。同一セッション内のセット数には依存しない。
- 記録を削除した場合、その分は累計の使用回数から差し引く。

### 4.2 セットの保存

- 必須項目がすべて入力されたセットのみを記録として保存する。
- テンプレート適用時に展開される空の入力欄は、入力が完了するまで保存しない。
- 必須項目が欠けたまま画面を離れた場合、そのセットは保存しない。

### 4.3 記録の編集・削除

#### 4.3.1 編集

編集できるのは当日の記録のみとする。過去日の記録は内容を書き換えられない。

| 操作 | 当日 | 過去日 |
|---|---|---|
| セットの重量・回数の修正 | 可能 | 不可 |
| セッション名の変更 | 可能 | 不可 |
| セッション内の種目の並び替え | 可能 | 不可 |
| 種目内のセットの並び替え | 可能 | 不可 |

- 上記以外の項目の編集は行えない。
- 並び替えの操作方法は基本設計で決定してよい。

#### 4.3.2 削除

削除は当日・過去日を問わず、以下の 3 単位で行える。

| 削除単位 | 影響範囲 | 確認ダイアログ |
|---|---|---|
| セット | 該当セットのみ削除する | 不要 |
| 種目 | セッション内のその種目と、配下の全セットを削除する | 必要 |
| セッション | そのセッションと、配下の全種目・全セットを削除する | 必要 |

- 誤登録の訂正は、削除して入力し直すことで行う。
- 削除したデータの復元機能は持たない。
- 削除の結果は、総ボリューム・種目別グラフ・期間サマリー・カレンダーの記録有無・種目の累計使用回数のすべてに即時反映する。

### 4.4 休憩タイマー

#### 4.4.1 開始と停止

- セットの入力欄には「完了」操作を設ける。完了操作を行うとセットが確定保存され、同時に休憩タイマーが自動的に開始する。
- タイマーの計測中も、次のセットの入力を開始できる。
- 目安秒数に達した時点で通知を行い、タイマーはそこで停止する。記録される休憩時間は目安秒数で頭打ちとなる。
- 計測中にユーザーが手動でタイマーを停止・リセットできる。
- アプリを閉じている間も計測が継続する。他のアプリを操作していてもタイマーが止まらないこと。

#### 4.4.2 記録

- 計測した休憩時間は、直前に完了したセットに紐づけて保存する。したがって最終セットの休憩時間は通常空になる。
- タイマーを手動停止した場合は、その時点までの経過秒数を記録する。
- タイマーを使わなかったセットの休憩時間は空のまま保存する。後からの手入力は行えない。

#### 4.4.3 設定

- 目安秒数はアプリ共通の設定値をひとつ持つ。種目ごとの個別設定は行わない。

### 4.5 通知

- 通知は休憩タイマーの終了通知のみとする。
- 通知は通知バーへの表示のみとし、音・バイブレーションは使用しない。
- 定刻・曜日指定のトレーニングリマインダー通知は対象外とする。

### 4.6 テンプレート（ルーティン）

- 種目の組み合わせをテンプレートとして保存できる。
- テンプレートに保存する内容は「種目」「その順番」「種目ごとのセット数」とする。
- 有酸素種目もテンプレートに含められる。有酸素種目はセット数を持たない扱いとする。
- テンプレートの作成・編集・削除ができる。テンプレート編集画面で種目の並び替えができる。
- テンプレートを適用すると、保存されたセット数の分だけ空の入力欄が展開される。重量・回数はその場で入力する。
- 適用先のセッションにすでに種目が存在する場合は、既存の記録を残したまま末尾に追記する。同一種目がすでに存在していても重複して追加してよい。
- 目標重量・目標回数はテンプレートに保存しない。
- 種目マスタから削除された種目は、その時点でテンプレートからも自動的に取り除かれる（3.4 参照）。

### 4.7 カレンダー表示

- 月間カレンダー上で、トレーニングを実施した日を確認できる。
- 日付マスに表示するのは「記録があるかどうかの印」のみとする。部位や総ボリュームの数値は表示しない。
- 筋トレのセットまたは有酸素の記録が 1 件以上存在する日を、トレーニング実施日とする。セッションだけが存在し配下の記録が 0 件の日は、実施日とみなさない。
- 日付をタップすると、その日の記録を開く。

### 4.8 総ボリュームの算出

総ボリュームは以下の式で算出する。

| 種目の種別 | 算出式 |
|---|---|
| 筋トレ・自重フラグなし | 重量 × 回数 をセットごとに算出し、合計する |
| 筋トレ・自重フラグあり | 体重 × 回数 をセットごとに算出し、合計する |
| 有酸素 | 総ボリュームを持たない。集計対象外 |

自重種目の算出に用いる体重は、以下の順序で決定する。

1. その日に体重記録があれば、その日の全記録の平均値を用いる。
2. その日に記録がなければ、記録が存在する直近の過去日を探し、その日の全記録の平均値を用いる。
3. 過去に一度も体重記録がない場合は、総ボリュームを 0 とする。

### 4.9 グラフ

#### 4.9.1 種目ごとの推移グラフ

- 種目を指定し、総ボリュームの推移を折れ線グラフで表示する。
- 同一日に同じ種目を複数のセッションで実施した場合は、その日の総ボリュームを合算し、日単位で 1 点として表示する。
- 表示期間はタブで切り替えられる。切り替え可能な期間は 1 ヶ月・3 ヶ月・1 年・全期間とする。
- 最大重量の推移、推定 1RM の推移は対象外とする。

#### 4.9.2 体重の推移

- 体重は「グラフ」と「一覧」の両方で確認でき、表示を切り替えられる。
- グラフでは、同じ日に複数件の記録がある場合、その日の平均値を 1 点として描画する。
- 一覧では、同じ日の複数件をすべて登録順に表示する。

### 4.10 期間サマリー

- 集計期間の単位は「週単位」と「月単位」の 2 つとする。
- 週の始まりは日曜日とする。
- 集計して表示する値は以下の 2 つとする。

  | 集計値 | 内容 |
  |---|---|
  | 総ボリューム合計 | 期間内の筋力トレーニング総ボリュームの合計 |
  | 部位ごとのボリューム内訳 | 筋トレ 6 部位（胸・背中・脚・肩・腕・体幹）ごとのボリューム内訳 |

- 部位は記録時点のスナップショット（3.4 参照）を用いて集計する。
- 有酸素種目は総ボリュームを持たないため、いずれの集計にも含めない。
- トレーニング実施日数、有酸素運動の合計実施時間の集計は対象外とする。

### 4.11 CSV 書き出し

#### 4.11.1 共通仕様

- 出力範囲は「全データの一括出力」と「開始日・終了日を指定した期間出力」の両方を選択できる。
- 期間出力では、開始日と終了日の両方を出力対象に含む。
- 筋トレ・有酸素・体重は種別ごとに別ファイルとして出力する（計 3 ファイル）。
- 文字コードは UTF-8（BOM 付き）とする。
- 出力先は端末のダウンロードフォルダとする。保存先を都度選ばせるダイアログや共有メニューは使用しない。
- ファイル名は以下の形式とする。日時を含めることで重複を避け、書き出すたびに別ファイルとして残る。

  | 種別 | ファイル名 |
  |---|---|
  | 筋トレ | `strength_YYYYMMDD_HHMMSS.csv` |
  | 有酸素 | `cardio_YYYYMMDD_HHMMSS.csv` |
  | 体重 | `weight_YYYYMMDD_HHMMSS.csv` |

- 値のエスケープは以下のとおりとする。カンマ・ダブルクォート・改行のいずれかを含む値はダブルクォートで囲み、値内のダブルクォートは 2 つ重ねて表現する。
- 日付は `YYYY-MM-DD` 形式で出力する。
- CSV の取り込み（インポート）機能は対象外とする。

#### 4.11.2 筋トレファイルの列構成

| 列 | 内容 |
|---|---|
| 日付 | 記録日 |
| セッション名 | 未入力の場合は空 |
| 種目 | 記録時点の種目名 |
| 部位 | 記録時点の部位 |
| セット数 | その行に含まれるセットの件数 |
| セット詳細 | 全セットの重量と回数を 1 セルにまとめて記述する（例: `60x10; 65x8; 65x6`）。自重種目は回数のみ記述する（例: `x10; x8`） |

- 出力の粒度は「1 種目 = 1 行」とする。
- 同じ日に同じ種目を複数のセッションで実施した場合は、セッションごとに行を分ける。
- 休憩時間、メモ、総ボリュームは出力しない。

#### 4.11.3 有酸素ファイルの列構成

| 列 | 内容 |
|---|---|
| 日付 | 記録日 |
| セッション名 | 未入力の場合は空 |
| 種目 | 記録時点の種目名 |
| 実施時間 | 分単位の整数 |

- 出力の粒度は「1 記録 = 1 行」とする。

#### 4.11.4 体重ファイルの列構成

| 列 | 内容 |
|---|---|
| 日付 | 記録日 |
| 体重 | kg 単位、小数第 1 位まで |

- 出力の粒度は「1 記録 = 1 行」とする。同じ日に複数件ある場合は登録順に複数行出力する。

## 5. 画面要件

- アプリ起動時に最初に表示する画面は「今日の記録画面」とする。
- 表示言語は日本語のみ、ライトテーマ固定、縦画面固定とする。

以下の画面が必要となる。

| 画面 | 目的 | 関連要件 |
|---|---|---|
| 今日の記録画面 | 起動直後に当日の記録を入力・確認する | 3.1, 3.6, 3.7, 4.2, 4.3, 4.4, 4.6 |

### 8.2 付録 B: 用語定義

| 用語 | 定義 |
|---|---|
| セッション | 1 回のトレーニングのまとまり。1 日に複数持てる |
| 種目 | ベンチプレスなど、個々のトレーニング動作。種目マスタで管理する |
| セット | 1 種目内の 1 回分の実施単位。重量と回数を持つ |
| 部位 | 種目に紐づく 7 区分の分類（胸・背中・脚・肩・腕・体幹・有酸素） |
| 自重種目 | 重量を入力せず、総ボリュームを体重 × 回数で算出する種目 |
| 総ボリューム | 4.8 の式で算出する値 |
| テンプレート | 種目・順番・セット数の組み合わせを保存したもの |
| スナップショット | 記録時点の種目属性のコピー。過去記録の表示と集計に用いる |
