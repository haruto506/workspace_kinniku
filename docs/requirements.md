- 文書バージョン: 2.0
- 作成日: 2026-09-05
- 想定読者: 基本設計を担当するエンジニア

## 0. この文書の読み方

- 「1. アプリケーション概要」から「8. 付録」までに記載された内容は、すべて依頼者との確認により確定した要件である。
- 確定していない事項は「9. 未決定事項」にのみ記載している。本文には推測による補完を含まない。基本設計に着手する前に、9章の各項目を依頼者に確認すること。

## 1. アプリケーション概要

筋力トレーニングおよび有酸素運動の実施内容を日々記録し、後から振り返るための個人用アプリケーション。

| 項目 | 内容 |
|---|---|
| 提供形態 | ネイティブ Android アプリ |
| 対応 OS | Android 13 以上 |
| 配布方法 | ビルドした APK を端末に直接インストール（ストア公開なし） |
| 利用者 | 依頼者本人ひとりのみ |
| データ保存先 | 端末内のみ（ローカル保存） |
| 表示言語 | 日本語のみ |
| 技術スタック | Kotlin ＋ Jetpack Compose ＋ Room |

## 2. 前提条件・制約

- サーバーおよびクラウドサービスは使用しない。すべての機能がオフラインで完結すること。
- ユーザーアカウント、ログイン、認証の仕組みは持たない。
- 複数端末間でのデータ同期は行わない。
- 多言語対応は行わない。
- ダークモードには対応しない。ライトテーマ固定とする。
- 画面は縦画面固定とする。端末を横にしても回転しない。

## 3. データモデルの基本構造

### 3.1 記録の階層

```
日付
 └ セッション（1 日に複数持てる。名前は任意）
     └ 種目（複数持てる。順番を持つ）
         └ セット（複数持てる。順番を持つ）
```

- 1 日に複数のセッションを登録できる。同じ日の朝と夜のトレーニングを別々の記録として扱える。
- セッションには任意で名前を付けられる。名前の入力は必須ではない。

### 3.2 種目マスタ

種目はマスタとして管理する。1 件の種目は以下の属性を持つ。

| 属性 | 内容 |
|---|---|
| 種目名 | 任意の文字列 |
| 部位 | 7 区分から 1 つ（3.3 参照） |
| 区分 | 「筋トレ」または「有酸素」 |
| 自重フラグ | 自重種目かどうか（3.5.2 参照）。有酸素種目では使用しない |

- 区分に応じて、記録時の入力項目を切り替える。
  - 筋トレ種目: 重量・回数を入力する
  - 有酸素種目: 実施時間を入力する
- ユーザーは種目を追加・編集・削除できる。追加時には部位・区分・自重フラグを設定する。
- 種目を削除した場合、その種目を使用している過去の記録は削除されずそのまま残る。削除された種目は新規記録時の種目一覧に表示されなくなるのみとする。過去記録の表示および集計には引き続き反映される。

### 3.3 部位

部位の区分はアプリ側で固定とし、ユーザーは部位の追加・変更・削除を行えない。部位は以下の 7 区分とする。

| 部位 | 用途 |
|---|---|
| 胸 | 筋トレ種目 |
| 背中 | 筋トレ種目 |
| 脚 | 筋トレ種目 |
| 肩 | 筋トレ種目 |
| 腕 | 筋トレ種目 |
| 体幹 | 筋トレ種目 |
| 有酸素 | 有酸素種目 |

### 3.4 種目の初期データ

- 筋トレ種目 55 件を初期登録する。具体的な種目名・部位・自重フラグは「8. 付録 A」に定める。
- 有酸素種目は初期登録しない。ユーザーが自分で追加する。

### 3.5 セットの記録項目（筋力トレーニング）

#### 3.5.1 通常の種目（自重フラグなし）

| 項目 | 内容 | 必須 |
|---|---|---|
| 重量 | 単位は kg のみ。0.5 kg 刻みで入力する | 必須 |
| 回数 | そのセットで行った反復回数 | 必須 |
| 休憩時間 | 休憩タイマーによる自動記録（4.3 参照）。タイマー未使用時は空のまま保存する | 任意 |
| メモ | フリーテキスト | 任意 |

#### 3.5.2 自重種目（自重フラグあり）

| 項目 | 内容 | 必須 |
|---|---|---|
| 回数 | そのセットで行った反復回数 | 必須 |
| 休憩時間 | 同上 | 任意 |
| メモ | 同上 | 任意 |

- 自重種目では重量を入力しない。
- ベルトでプレートを下げるなどの加重は記録しない。加重して記録したい場合は、ユーザーが別の種目として自分で登録する。

#### 3.5.3 対象外の項目

- RPE・主観的なきつさの記録は行わない。

### 3.6 有酸素運動の記録項目

| 項目 | 内容 | 必須 |
|---|---|---|
| 種目 | 種目マスタの有酸素種目から選択する | 必須 |
| 実施時間 | 分単位の整数で入力する | 必須 |

対象外の項目: 距離、消費カロリー、心拍数・強度の記録は行わない。

### 3.7 体重の記録

| 項目 | 内容 |
|---|---|
| 体重 | 単位は kg のみ。0.1 kg 刻みで入力する |

- 日付ごとに体重を記録できる。
- 1 日に何件でも記録できる。
- 体脂肪率、体のサイズ（胸囲・腕回りなど）の記録は対象外とする。

## 4. 機能要件

### 4.1 種目の選択

- 種目を選択する画面では、累計の使用回数が多い順に種目を並べる。
- 累計の使用回数とは、その種目が記録に使用された回数の総計を指す。

### 4.2 記録の編集・削除

#### 4.2.1 編集

編集できるのは当日の記録のみとする。過去日の記録は内容を書き換えられない。

| 操作 | 当日 | 過去日 |
|---|---|---|
| セットの重量・回数の修正 | 可能 | 不可 |
| セッション名の変更 | 可能 | 不可 |

- 上記以外の項目の編集は行えない。

#### 4.2.2 削除

削除は当日・過去日を問わず、以下の 3 単位で行える。

| 削除単位 | 影響範囲 |
|---|---|
| セット | 該当セットのみ削除する |
| 種目 | セッション内のその種目と、配下の全セットを削除する |
| セッション | そのセッションと、配下の全種目・全セットを削除する |

- 誤登録の訂正は、削除して入力し直すことで行う。

### 4.3 休憩タイマー

- セット間の休憩時間はアプリ内タイマーで計測し、自動的に記録する。
- 計測した休憩時間は、直前に完了したセットに紐づけて保存する。したがって最終セットの休憩時間は通常空になる。
- 目安秒数を設定でき、その秒数に達した時点で通知を行い、タイマーはそこで停止する。記録される休憩時間は目安秒数で頭打ちとなる。
- 目安秒数はアプリ共通の設定値をひとつ持つ。種目ごとの個別設定は行わない。
- アプリを閉じている間も計測が継続する。他のアプリを操作していてもタイマーが止まらないこと。
- 計測中にユーザーが手動でタイマーを停止・リセットできる。
- タイマーを使わなかったセットの休憩時間は空のまま保存する。後からの手入力は行えない。

### 4.4 通知

- 通知は休憩タイマーの終了通知のみとする。
- 通知は通知バーへの表示のみとし、音・バイブレーションは使用しない。
- 定刻・曜日指定のトレーニングリマインダー通知は対象外とする。

### 4.5 テンプレート（ルーティン）

- 種目の組み合わせをテンプレートとして保存できる。
- テンプレートに保存する内容は「種目」「その順番」「種目ごとのセット数」とする。
- 有酸素種目もテンプレートに含められる。有酸素種目はセット数を持たない扱いとする。
- テンプレートを適用すると、保存されたセット数の分だけ空の入力欄が展開される。重量・回数はその場で入力する。
- 目標重量・目標回数はテンプレートに保存しない。
- テンプレートの作成・編集・削除ができる。

### 4.6 カレンダー表示

- 月間カレンダー上で、トレーニングを実施した日を確認できる。
- 日付マスに表示するのは「記録があるかどうかの印」のみとする。部位や総ボリュームの数値は表示しない。
- 日付をタップすると、その日の記録を開く。

### 4.7 総ボリュームの算出

総ボリュームは以下の式で算出する。

| 種目の種別 | 算出式 |
|---|---|
| 筋トレ・自重フラグなし | 重量 × 回数 をセットごとに算出し、合計する |
| 筋トレ・自重フラグあり | 体重 × 回数 をセットごとに算出し、合計する |
| 有酸素 | 総ボリュームを持たない。集計対象外 |

- 自重種目の算出に用いる体重は、その日にもっとも近い体重記録の値とする。その日の記録がなければ直前の記録を用いる。体重を一度も記録していない場合は総ボリュームを 0 とする。

### 4.8 グラフ

#### 4.8.1 種目ごとの推移グラフ

- 種目を指定し、総ボリュームの推移を折れ線グラフで表示する。
- 表示期間はタブで切り替えられる。切り替え可能な期間は 1 ヶ月・3 ヶ月・1 年・全期間とする。
- 最大重量の推移、推定 1RM の推移は対象外とする。

#### 4.8.2 体重の推移

- 体重は「グラフ」と「一覧」の両方で確認でき、表示を切り替えられる。
- グラフでは、同じ日に複数件の記録がある場合、その日の平均値を 1 点として描画する。

### 4.9 期間サマリー

- 集計期間の単位は「週単位」と「月単位」の 2 つとする。
- 週の始まりは日曜日とする。
- 集計して表示する値は以下の 2 つとする。

  | 集計値 | 内容 |
  |---|---|
  | 総ボリューム合計 | 期間内の筋力トレーニング総ボリュームの合計 |
  | 部位ごとのボリューム内訳 | 筋トレ 6 部位（胸・背中・脚・肩・腕・体幹）ごとのボリューム内訳 |

- 有酸素種目は総ボリュームを持たないため、いずれの集計にも含めない。
- トレーニング実施日数、有酸素運動の合計実施時間の集計は対象外とする。

### 4.10 CSV 書き出し

#### 4.10.1 共通仕様

- 出力範囲は「全データの一括出力」と「開始日・終了日を指定した期間出力」の両方を選択できる。
- 筋トレ・有酸素・体重は種別ごとに別ファイルとして出力する（計 3 ファイル）。
- 文字コードは UTF-8（BOM 付き）とする。
- 出力先は端末のダウンロードフォルダとする。保存先を都度選ばせるダイアログや共有メニューは使用しない。
- ファイル名は日時を含めることで重複を避ける。書き出すたびに別ファイルとして残る。
- CSV の取り込み（インポート）機能は対象外とする。

#### 4.10.2 筋トレファイルの列構成

| 列 | 内容 |
|---|---|
| 日付 | 記録日 |
| セッション名 | 未入力の場合は空 |
| 種目 | 種目名 |
| 部位 | 7 区分のいずれか |
| セット数 | その行に含まれるセットの件数 |
| セット詳細 | 全セットの重量と回数を 1 セルにまとめて記述する（例: `60x10; 65x8; 65x6`） |

- 出力の粒度は「1 種目 = 1 行」とする。
- 同じ日に同じ種目を複数のセッションで実施した場合は、セッションごとに行を分ける。
- 休憩時間、メモ、総ボリュームは出力しない。

## 5. 画面要件

- アプリ起動時に最初に表示する画面は「今日の記録画面」とする。
- 表示言語は日本語のみ、ライトテーマ固定、縦画面固定とする。

以下の画面が必要となる。

| 画面 | 目的 | 関連要件 |
|---|---|---|
| 今日の記録画面 | 起動直後に当日の記録を入力・確認する | 3.1, 3.5, 3.6, 4.2, 4.3, 4.5 |
| 種目選択画面 | 記録する種目を選ぶ | 4.1 |
| 種目マスタ管理画面 | 種目の追加・編集・削除 | 3.2 |
| テンプレート管理画面 | テンプレートの作成・編集・削除・適用 | 4.5 |
| カレンダー画面 | 実施日の一覧と過去記録への遷移 | 4.6 |
| 過去記録の参照画面 | 過去日の記録の閲覧と削除 | 4.2 |
| 種目別グラフ画面 | 総ボリュームの推移確認 | 4.8.1 |
| 体重画面 | 体重の記録、グラフと一覧の表示切替 | 3.7, 4.8.2 |
| 期間サマリー画面 | 週・月単位の集計表示 | 4.9 |
| CSV 書き出し画面 | 出力範囲の指定と書き出し実行 | 4.10 |
| 設定画面 | 休憩タイマーの目安秒数の設定 | 4.3 |

## 7. スコープ外（実装しない機能）

依頼者の判断により、以下は今回の開発対象に含めない。

- 目標設定・達成度管理（目標重量、週あたり実施回数など）
- 写真・動画の添付
- 他アプリ連携（Google Fit、ヘルスケアアプリ、ウェアラブル端末など）
- SNS 共有、他ユーザーとの交流、ランキング
- ユーザーアカウント、ログイン、複数ユーザー対応
- クラウド保存、複数端末間の同期
- CSV 以外のバックアップ・復元、および CSV インポート
- 入力画面での前回記録の表示
- 定刻リマインダー通知
- 休憩タイマー終了時の音・バイブレーション
- 自重種目への加重の記録
- RPE、距離、消費カロリー、心拍数、体脂肪率、体のサイズの記録
- 最大重量および推定 1RM のグラフ
- トレーニング実施日数、有酸素合計時間の集計
- 部位区分のユーザーによる編集
- 過去日の記録内容の編集
- 休憩時間の手入力
- ダークモード対応
- 横画面対応
- 多言語対応

| 用語 | 定義 |

## 9. 未決定事項

基本設計の着手前に依頼者への確認が必要な事項。本要件定義書ではいずれも決定していない。

### 9.1 時間で行う体幹種目の記録方法

- 付録 A に含まれるプランク、サイドプランクは秒数で実施する種目だが、筋トレ種目の入力項目は重量と回数のみと定めている。回数欄に秒数を入力する運用とするか、これらの種目を初期リストから除外するか、時間入力に対応させるかが未決定。

### 9.2 体重記録の識別方法

- 体重は 1 日に何件でも記録できると定めているが、同じ日の複数件をどう区別するかが未決定。記録に時刻を持たせるかどうかを確認すること。

### 9.3 CSV の列構成（有酸素・体重）

- 筋トレファイルの列構成は 4.10.2 に定めたが、有酸素ファイルと体重ファイルの列構成は未決定。
- 有酸素ファイルの粒度（1 種目 = 1 行とするか）も未決定。

### 9.4 その他

- 想定するデータ件数の規模、およびデータの保持期間の上限。
- タブレットなど大画面端末でのレイアウト最適化の要否（縦画面固定は決定済み）。
- 休憩タイマーの目安秒数の初期値。
